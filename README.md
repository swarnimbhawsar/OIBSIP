# OIBSIP Data Analytics Internship

This repository contains the projects completed as part of my **Data Analytics Internship**.

The projects demonstrate practical applications of **Python, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn** for data exploration, customer segmentation and data cleaning.

---

## 📌 Projects

### Task 1 — Exploratory Data Analysis on Retail Sales

**Notebook:** `Task_1_EDA_Retail_Sales.ipynb`

Performed Exploratory Data Analysis on retail sales data to identify:

- Overall sales performance
- Monthly and quarterly sales trends
- Customer demographics
- Product-category performance
- Revenue patterns
- Relationships between numerical variables
- Business insights from visualizations

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

---

### Task 2 — Customer Segmentation

**Notebook:** `Task_2_Customer_Segmentation.ipynb`

Performed customer segmentation using **RFM Analysis and K-Means Clustering**.

The analysis examined:

- Recency
- Frequency
- Monetary value
- Customer purchasing behaviour
- Customer clusters
- Cluster characteristics
- PCA-based visualization
- Customer segment interpretation

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

---

### Task 3 — Data Cleaning

**Notebook:** `Task_3_Data_Cleaning.ipynb`

Performed a complete data-cleaning workflow including:

- Missing-value detection and handling
- Duplicate detection and removal
- Column-name standardization
- Data-type conversion
- Text formatting
- Invalid-value detection
- Outlier detection using the IQR method
- Outlier treatment
- Data-quality validation
- Export of the cleaned dataset

**Output Dataset:** `cleaned_retail_sales.csv`

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn
